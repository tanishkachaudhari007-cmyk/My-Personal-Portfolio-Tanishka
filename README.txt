TANISHKA CHAUDHARI — PORTFOLIO

OPEN LOCALLY
1. Extract this ZIP.
2. Open the folder.
3. Double-click index.html to open it in your browser.

WELCOME, LOGIN AND SIGNUP
The welcome page has Explore Portfolio, Login and Sign Up. Visitors can open the portfolio without logging in. Login/signup are demo-only and use localStorage in the browser. This is NOT secure authentication and must not be used for real accounts or sensitive data.

IMAGES
The assets folder contains the profile photo, project screenshots and certificates. Keep the folder and filenames unchanged.

PUBLISH
For GitHub Pages, upload the contents of this folder to a repository and enable Pages in Settings > Pages. Since this is a static site, demo login is not a real account system.
